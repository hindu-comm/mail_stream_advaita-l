//Thanks for the explanation. Would you say this such distinction is
clearly mentioned between jnAni's experiences of bAdhita-anuvRitti being
not applicable to DSV explanation and not just to the ajAta type dRShTi.//

Yes. Advaita-siddhi clearly holds in eka-jIva-vAda-vichArah that there has
never been any jnAnI. On account of the fact that we can perceive the
world. Had there been any jnAnI, world being avidyA-kArya would have been
sublimated.

Since there has been no jnAnI, there is no discussion possible on
bAdhita-anuvritti as it would be non-starter.

//Please note that in that case DSV and ajAta explanations would be no
different on this question of where there is jnAni's "continuation"?//

Post-jnAna, there is no difference between DSV and ajAti. It is pre-jnAna
that there is a difference between DSV and ajAti.
