Namaste Subbu ji,

As I understand, if A is the visheshya having B as the visheshaNa, which in
turn has C as visheshaNa, then A has C-vishishTa-B-vaishishTya.

VaishishTya = vishishTa-tva.

So, in the ChhAndOgya case, the knowledge अरुणनेत्रवान् पुरुषः, is a clear
example of vishishTa-vaishishTya-avagAhi-jnAna.

A = purusha, B = aruNa-netra, C = aruNatva.

It is like नीलघटवान् चैत्रः. Here, A = Chaitra, B = neela-ghaTa, C =
neela-tva.

I don't think upama will play any role..so, whether that aruNa is like
lotus or kapyAsa, that hardly matters.

Regards.
Sudhanshu Shekhar.
